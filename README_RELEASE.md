# Albert — переносимая версия для Windows

Требуется установленный **AutoHotkey v2**, Windows 10/11, MicroSIP,
Telegram Desktop и Chrome либо Edge. ZIK в этой версии отсутствует.

## Первая настройка

1. Создайте папку `C:\Albert` и поместите туда `Albert-V2.ahk`.
2. Закрепите приложения в панели задач именно в этом порядке:
   **1 — MicroSIP, 2 — Telegram, 3 — браузер, 4 — калькулятор**.
3. Запустите `Albert-V2.ahk`. Введите полное имя для SAP и подпись для
   Telegram (например `#Abdulloh`). Поля независимы.
4. Проверьте автоматически найденные пути MicroSIP, `microsip.ini`, Telegram
   и браузера. При необходимости нажмите «Выбрать…».
5. При желании укажите таблицы размеров и адресов. Пустые поля пропускаются.
6. Нажмите «Сохранить и включить». Albert создаст `Albert.lnk` в автозагрузке
   текущего пользователя. **Сразу после настройки программы не открываются.**

Albert не копирует себя в другую папку и не переносит рабочие таблицы.
Настройки `settings.ini` и журнал `activity_log.txt` создаются рядом со скриптом.
Текущему пользователю нужен доступ на запись в `C:\Albert`.
При передаче скрипта другому сотруднику не передавайте свои INI и журнал.

## Вход в Windows

Ярлык запускает Albert с аргументом `--startup`. Через 10 секунд после запуска:

| Стол | Программы |
|---|---|
| 1 | Albert ничего не открывает |
| 2 | Telegram, MicroSIP, Bitrix |
| 3 | Калькулятор, склад |
| 4 | Указанные таблицы |

Недостающие столы создаются; существующие не удаляются. После запуска
Albert возвращается на стол 2. Ссылки Bitrix и склада общие и встроены в скрипт.
Обычный ручной запуск или Reload **не запускает рабочее окружение повторно**.

Если раньше использовался отдельный `start.ahk`, удалите **его ярлык/файл из
автозагрузки вручную**, чтобы старый сценарий не запускался вместе с Albert.
Albert чужие элементы автозагрузки не удаляет.
Для предсказуемого размещения отключите отдельную автозагрузку Telegram/MicroSIP
и автоматическое восстановление рабочих окон Windows: уже запущенные
программы Albert не дублирует, но не переносит их окна с других столов.
Во время раскладки дождитесь окончания переключений, не меняя активные окна.

## F10 — настройки

- Пути программ, таблиц, полное имя и подпись сотрудника.
- «Статусы F2/F3/F4» — прежние настройки статусов.
- «Филиалы» — добавить, изменить или удалить пару **точное название склада →
  название группы Telegram**. Для добавления после выбора существующей записи
  нажмите «Очистить поля». Изменения сохраняются сразу.

По умолчанию загружается встроенный список. В нём исправлены:
`AN - ASKO Andijon → ANDIJON ASKO`, `AR - ASKO Angren → Angren call center`.
После первого изменения используется сохранённый список, поэтому удалённые
филиалы не появляются заново. Неизвестный филиал останавливает отправку
с предложением добавить его через F10.

## Рабочие функции

- F11: BITRIX ↔ SVERKA. F12: SAP → TELEGRAM → MICROSIP → SAP.
- PgUp работает как обычная клавиша; макрос с логином и паролем удалён.
- F6: завершить MicroSIP, записать `DND=1` в выбранный INI, снова запустить
  выбранный исполняемый файл. В NORMAL остаётся обычной F6.
- Клавиша тильды: первый выделенный товар, проверка остатка от 4 штук,
  калькулятор и отправка в текущую группу Telegram, затем в группу филиала.
  Используется подпись настроенного сотрудника. Текущий чат и поле с номером
  нужно подготовить заранее. Поиск группы зависит от интерфейса Telegram.

## Обновление и удаление

Для обновления замените только `Albert-V2.ahk` и перезапустите его.
Сохраните `settings.ini` и `activity_log.txt`. Не запускайте одновременно
старую и новую копии из разных папок.
Для отключения автозагрузки удалите `Albert.lnk` из папки `shell:startup`.

## Проверки разработчика

`python tests/check_logic.py` проверяет синтаксис AHK, скрытое построение окон
настроек, ярлык во временной папке, сохранение филиалов и статистики,
распознавание товаров и аналитику. Реальная отправка сообщений, перезапуск
MicroSIP и вход в Windows в автоматическом тесте не выполняются.
